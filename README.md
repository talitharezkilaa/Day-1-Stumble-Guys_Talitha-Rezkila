## 1. Deskripsi Repository

Repository ini berisi project Student Task Planner yang dibuat sebagai bagian dari kegiatan Workshop Day 1 TIK MENGAJAR. Aplikasi ini dibuat untuk membantu mahasiswa mengatur tugas kuliah, mulai dari mencatat tugas, menentukan deadline, sampai memantau tugas yang sudah selesai.

Tujuan dari repository ini adalah sebagai tempat penyimpanan project sekaligus dokumentasi proses pembuatan dan pengembangan aplikasi menggunakan AI, Git, dan GitHub. 

Terutama dalam repository ini terdapat projek web yang berisi tentang student task planner yang sudah di buat berdasarkan perintah selama workshop di hari ini.

## 2. Dokumentasi Kegiatan Workshop

Day 1 Workshop membahas tentang *Building with AI, Managing Change with GitHub* yang disampaikan oleh Nugi Farhan selaku Senior Product Designer.

Materi pertama membahas penggunaan AI dalam proses pembuatan aplikasi. Salah satu hal yang ditekankan adalah pentingnya menyusun prompt dengan jelas agar AI dapat memahami instruksi yang diberikan. Dalam menyusun prompt, ada beberapa bagian yang bisa digunakan, yaitu Role, Task atau Goal, Context, Constraints, dan Format atau Output. Penting juga untuk mention batasan dalam membuat prompt AI sehingga dapat mempermudah jawaban dari maksud yang dituju.

Selanjutnya, workshop juga membahas Git dan GitHub. Git merupakan tools untuk mencatat dan mengelola perubahan pada project, sedangkan GitHub digunakan sebagai tempat menyimpan repository secara online. Dengan keduanya, proses pengembangan project bisa lebih teratur karena setiap perubahan dapat dicatat dan diakses kembali.


Dari workshop ini, ada beberapa hal baru yang dipelajari. Salah satunya adalah cara membuat prompt yang lebih terarah, bukan sekadar memberikan perintah singkat kepada AI.

Disini juga mulai memahami tentang penggunaan Git, terutama tiga area utamanya, yaitu Working Directory, Staging Area, dan Git Directory. Selain itu, Mempraktikkan beberapa command dasar seperti `git init`, `git add`, `git commit`, dan `git push` untuk mengelola serta mengunggah project ke GitHub.

Hal lainnya yang didapat adalah pemahaman bahwa membuat aplikasi dengan AI bukan berarti hanya menerima hasil jadi. Kita tetap perlu mengecek, memahami, dan melakukan perubahan sesuai kebutuhan project.


Menurut pendapat saya, kegiatan workshop ini cukup menarik dan bermanfaat, terutama karena peserta tidak hanya mendapatkan materi, tetapi juga langsung mencoba membuat project sendiri.

Awalnya, penggunaan Git dan GitHub terasa cukup membingungkan karena ada beberapa command yang belum familiar. Namun, setelah dicoba secara langsung, saya pribadi mulai memahami bagaimana proses menyimpan perubahan dan mengunggah project ke repository.

Juga dalam hal ini jadi lebih tahu bagaimana memanfaatkan AI sebagai alat bantu dalam membuat aplikasi. Sehingga, hal ini lah yang paling penting bukan hanya mendapatkan hasil dari AI, tetapi juga memahami bagaimana hasil tersebut dibuat dan bagaimana cara mengembangkannya lagi.

Overall, Day 1 Workshop menjadi pengalaman baru yang cukup menyenangkan dan menambah pengetahuan tentang penggunaan AI serta GitHub dalam pengembangan aplikasi.
